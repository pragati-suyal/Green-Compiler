About Green Compiler

Green Compiler is a static code analysis project that estimates code energy scores using heuristic rules. It helps developers identify potentially expensive code patterns such as nested loops and frequent input/output operations.

Note: The score is a heuristic estimate, not a direct measurement of electricity consumption.
